# Rallii Rail native delivery and OTA updates

Rallii Rail uses Capacitor for iOS and Android containers and a self-hosted, zero-server OTA model. The web app remains on Vercel; native releases bundle the static `out/` directory generated by `npm run native:build`.

## OTA architecture

There is no Capgo-hosted service and no Rallii OTA backend. The app-side updater in `src/lib/ota-updater.ts` checks this static R2 manifest:

`<R2_PUBLIC_BASE_URL>/updates/com.rallii.rail/<channel>/manifest.json`

The on-device Capgo plugin is in manual mode. It only verifies and decrypts encrypted bundles supplied by Rallii's manifest. It does not automatically check Capgo.

The updater applies only a numerically newer manifest, schedules the downloaded bundle for the next launch, and calls `notifyAppReady()` after a healthy launch so the local rollback guard remains active.

## GitHub configuration

Required Actions secrets:

- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN`
- `R2_BUCKET_NAME`
- `CAPGO_PRIVATE_KEY` — base64 of the private key file; CI-only

Required Actions variables:

- `R2_PUBLIC_BASE_URL` — `https://pub-9fa41a6ec38e4064b998f30a35df2cb0.r2.dev`
- `TRAVELPAYOUTS_TRS` and `TRAVELPAYOUTS_MARKER` if native builds should include the existing partner widgets

The matching RSA public key is committed in `capacitor.config.ts`. That is safe and intentionally required by the on-device decryption flow.

## Publishing an OTA update

In GitHub Actions, run **Publish OTA Update (zero-server)** and choose `staging` or `production`. It builds the static native bundle, encrypts it with the private key, uploads the immutable bundle to R2, and writes `manifest.json` last.

Publish to staging first, test it on a staging device/build, then explicitly publish the same commit to production. OTA is for web-layer changes only: interface, editorial content, route data, and compatible web behavior. Native plugins, permissions, config, signing, icons, or public-key rotation require a new store binary.

## Native projects and cloud builds

`ios/` and `android/` are committed and synced from the same static `out/` bundle. This does not require owning a Mac: GitHub Actions macOS runners compile iOS. A small local Capacitor user-info shim keeps the Windows CLI usable when Node cannot read the current Windows user profile; it changes no app or OTA behavior.

## September 2026 delivery repair

The legacy `/updates/<channel>/manifest.json` path was shared with Let Them Eat Cake. Its commit `953119abf404d80d4897f89f9e8b21103630993e` replaced the Rallii `60437e6` production manifest after publication. Rallii now publishes only under `/updates/com.rallii.rail/<channel>/`, and the client validates the app identity and exact bundle location before downloading. Do not republish Rallii to the shared legacy path. Existing installations that still poll that path need a replacement native build to migrate safely; the isolated OTA alone cannot redirect them.
