# Rallii Product Principles

- Rallii is an experience layer for rail journeys, not a railway infrastructure platform.
- Best Side to Sit, Scenic Journey Timeline, Interactive Railway Map, and Landmark Intelligence are the primary differentiators.
- Start with one route and expand gradually.
- Use prepared route geometry rather than performing live railway routing.
- Keep railway-source data separate from Rallii editorial intelligence.
- No artificial gamification.
- Avoid adding features that are not required for the current milestone.
